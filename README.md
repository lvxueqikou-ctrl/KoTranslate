# KoTranslate 1.3.9.8

轻量的 KOReader 翻译与辅助阅读插件。

## 功能

- Microsoft Edge 免费翻译
- Google 免费翻译
- 生成本书译文
- 生成本章译文
- 中文译文显示/隐藏
- 日文假名与罗马音辅助阅读
- 日文汉字词典辅助阅读
- 英文分级释义辅助阅读
- 辅助阅读字号、颜色调整
- 翻译缓存与断点续跑
- 清除当前书籍译文
- 不修改原书，不生成新的双语 EPUB

## 支持格式

- EPUB：完整支持
- FB2：支持正文翻译与辅助阅读
- TXT：支持按自然段翻译与辅助阅读

其他格式建议先转换为 EPUB 后使用。

## 安装

退出 KOReader，将 `kotranslate.koplugin` 文件夹复制到：

`koreader/plugins/`

然后重新启动 KOReader。

## 注意

翻译和词典功能需要联网。翻译内容保存在 KOReader 独立缓存中，删除译文只会删除当前书籍的缓存，不会修改原始文档。
